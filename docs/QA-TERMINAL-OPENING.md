## Aset dan anggaran

Trace/orbit monitor lama dihapus. Model terbaru: **248 mesh, 90.432 rendered triangle, 182 geometri, 12 tekstur**. Tekstur monitor dinaikkan dari 768×432 menjadi 1536×864 agar close-up lebih tajam; memori tekstur naik walau jumlahnya tetap. Semua **21 poster** dibuat ulang dari scene paused, total **794.568 byte**. Tidak menambah GLB/aset pihak ketiga. Source renderer/controls/model/lisensi lama tetap.

Metadata-only 21st Terminal Loader 24397 dan Modern Loader 29852 diperiksa untuk pola terminal; tidak mengambil kode berbayar/generation atau menambah library. Painter proyek dipakai supaya handoff cocok dengan geometri monitor, readiness nyata dan cleanup yang sudah ada.

## Pemeriksaan

- `npm run build` lulus, termasuk TypeScript, validasi konten, **15 tes** dan syntax prototype. Tes memeriksa typing terminal dan gate readiness, stroke/koreksi/jeda; geometri memeriksa tepat satu cap turun, semua cap dilepas pada boot dan tekstur tidak diunggah ulang saat isi tetap. Tes kamera diperbarui untuk corridor monitor, endpoint, kontinuitas dan retarget.
- Source lint UI tiga file: **0 FAIL/0 WARN**. Diff whitespace/JSON desain diperiksa saat handoff.
- Dev boot suite lulus desktop/mobile, handoff/reveal, satu renderer, reload/route tanpa replay, Skip, hidden, reduced, saved pause/static, direct Writing, noWebGL/noJS, deadline dan late import. PageErrors kosong. Screenshot terminal/pullback/Home dibuka; resolusi awal ditingkatkan setelah review.
- QA screenshot memperpanjang hold handoff menjadi 1200ms agar fase produk 360ms tidak terlewat automation. Fixture timeout setelah typing mempercepat hanya deadline 12s menjadi 1500ms sambil menahan dynamic import 3000ms; fixture early timeout 300ms memeriksa tidak ada restart dan retry eksplisit. Ini perubahan fixture browser, bukan durasi produk.
- Lima suite produksi lulus setelah koreksi canvas noJS: boot, cinematic-camera, personal-lab lifecycle, smoke dan navigation; pageErrors kosong. Boot memeriksa Escape/fokus dan live reduced-motion; kamera memakai matriks view WebGL aktual untuk memeriksa pullback/rise, retarget dan resize. Lifecycle memeriksa pixel pause/orbit/reset, context loss/retry, static dan touch. Build/check akhir dan boot diulang setelah koreksi CSS handoff visual terakhir: lulus, opacity monitor penuh dan screenshot terminal tanpa ghost poster. Tidak mengulang suite 30 arah text-transition karena runtime route-fade tidak diubah; cinematic/navigation memeriksa jalur yang relevan.
- Inspector Home menetap pada desktop/tablet/mobile (`?preview=1#main` sengaja melewati opening) tetap **3 FAIL/3 WARN**, bukan audit desain penuh lulus. Temuan generik: accent hangat, sedikit raster dan hitungan motion DOM tidak mewakili canvas; pill nav, tanpa footage dan headline nama. Ini mengikuti arah pemilik, scene asli dan copy yang sudah disetujui; tidak menambah foto/video/gerak dekoratif untuk memenuhi meter. Ketiga screenshot fold serta terminal/pullback/Home dibuka.

## Batas dan penggunaan

Opening bukan unduhan seluruh konten situs. Tidak mengklaim semua media masa depan sudah dimuat atau FPS yang sama pada semua perangkat. HP fisik, Safari/Firefox, zoom/screen reader menyeluruh dan GPU/memory jangka panjang belum diuji. Tidak ada deployment atau perubahan Git yang di-stage/commit/push.
