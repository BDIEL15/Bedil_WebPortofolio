## Start with a question

Replace this text with your own writing. Add `publishedAt: YYYY-MM-DD` and
set `status: published` only when the article is ready.

MDX supports owner-authored React components registered in the article renderer.
Use `.md` for ordinary writing. Never place draft assets in `public/`.
